# 📦 SwiPex Pro v3.0

تطبيق احترافي لإدارة توصيل الطرود - مصمم خصيصاً لشركة ياليدين وخدمات التوصيل في الجزائر.

## 🌟 نظرة عامة

SwiPex Pro هو تطبيق ويب تقدمي (PWA) متقدم يعمل على جميع الأجهزة (هاتف، تابلت، كمبيوتر) ويمكن تثبيته كتطبيق مستقل. يوفر واجهة سهلة وسريعة لإدارة الطرود وتتبع حالاتها مع مزامنة سحابية فورية عبر الأجهزة باستخدام Firebase و Google Sheets.

## ✨ المميزات

### 🔐 تسجيل الدخول والمزامنة السحابية
- تسجيل دخول آمن بحساب Google (Firebase Authentication)
- **مزامنة فورية في الوقت الفعلي** عبر Cloud Firestore باستخدام Realtime Listeners
- حفظ احتياطي تلقائي في Google Sheets مع تجديد ذكي للتوكن
- حفظ محلي في localStorage للعمل بدون إنترنت
- ترتيب أولوية التحميل: Firestore → Google Sheets → localStorage
- كشف تلقائي لحالة الإنترنت والتبديل بين الأوضاع
- تتبع حالة المزامنة (syncing / synced / offline / error)

### 📦 إدارة الطرود
- **استيراد ذكي من PDF** - محلل متقدم لملفات ياليدين يستخرج جميع البيانات تلقائياً:
  - بيانات المستلم (الاسم، العنوان، البلدية، الولاية، رقمي الهاتف)
  - بيانات المرسل (الاسم، العنوان، رقمي الهاتف)
  - تفاصيل الطرد (رقم التتبع، النوع، PIN، المحتوى، المبلغ، التاريخ)
- **استيراد من Excel/CSV** مع دعم الأعمدة بالعربية والفرنسية
- إضافة طرود يدوياً مع نموذج شامل
- تعديل كامل لبيانات المستلم والمرسل
- حذف آمن مع نافذة تأكيد
- **إعادة ترتيب بالسحب والإفلات** (Drag & Drop) مع حفظ تلقائي
- **كشف تلقائي للأرقام المكررة** مع شارة تنبيه ملونة
- تصدير النتائج إلى Excel بجميع التفاصيل
- مشاركة الجلسة مع زملاء العمل عبر ملف Excel

### متطلبات الإعداد

#### 1. إعداد Firebase
1. أنشئ مشروع جديد في [Firebase Console](https://console.firebase.google.com)
2. فعّل **Authentication**:
   - اذهب إلى Authentication > Sign-in method
   - فعّل Google Provider
   - أضف النطاق الخاص بك في Authorized domains
3. فعّل **Cloud Firestore**:
   - أنشئ قاعدة بيانات
   - ابدأ بوضع Production mode
4. أضف قواعد الأمان في Firestore:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // السماح للمستخدمين المسجلين فقط بقراءة/كتابة بياناتهم
    match /users/{userId}/data/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

5. انسخ Firebase Config من Project Settings واستبدلها في `login.html` و `index.html`

#### 2. تمكين Google Sheets API (اختياري)
1. اذهب إلى [Google Cloud Console](https://console.cloud.google.com)
2. فعّل Google Sheets API و Google Drive API
3. لا حاجة لإعداد إضافي - يتم الحصول على التوكن تلقائياً عند تسجيل الدخول

## 💾 نظام حفظ البيانات (3 مستويات)

### 1. localStorage (المستوى الأول)
- حفظ فوري ومحلي
- يعمل بدون إنترنت
- حجم غير محدود تقريباً
- الأسرع في القراءة والكتابة

### 2. Cloud Firestore (المستوى الثاني)
- **مزامنة فورية في الوقت الفعلي** (Realtime Sync)
- يستخدم Realtime Listeners للتحديث الفوري عبر الأجهزة
- حفظ تلقائي بعد كل تعديل (debounced 500ms)
- يعمل بين جميع الأجهزة المسجلة بنفس الحساب
- أمان عالي مع Firebase Security Rules

### 3. Google Sheets (المستوى الثالث)
- حفظ احتياطي إضافي
- يمكن الوصول للبيانات من Google Sheets مباشرةً
- تجديد تلقائي للـ Access Token عند انتهائه
- يحفظ سجل التغييرات (Changes Log) في ورقة منفصلة
- مفيد للمراجعة والتحليل

### آلية التحميل
```
1. تحميل فوري من localStorage (أسرع)
2. الاستماع الفوري لتحديثات Firestore (Realtime Listener)
3. تحديث تلقائي عند ورود بيانات جديدة من Firestore
4. Google Sheets كنسخة احتياطية إضافية
```

### آلية الحفظ
```
1. حفظ فوري في localStorage
2. حفظ تلقائي في Firestore (debounced 500ms)
3. حفظ دوري في Google Sheets (عند الاتصال بالإنترنت)
```

## 🔧 استكشاف الأخطاء

### المشاكل الشائعة

#### 1. لا يعمل تسجيل الدخول
- تأكد من تفعيل Google Provider في Firebase Console
- تأكد من إضافة النطاق في Authorized domains
- تحقق من Firebase Config في `login.html`
- امسح الكاش وحاول مرة أخرى

#### 2. لا تعمل المزامنة
- تأكد من الاتصال بالإنترنت
- تحقق من قواعد Firestore Security Rules
- راجع Console للأخطاء
- تأكد من تسجيل الدخول بنفس الحساب

#### 3. لا يعمل Google Sheets
- تأكد من تمكين Sheets API في Google Cloud Console
- تحقق من صلاحيات OAuth (Scopes)
- قد تحتاج لإعادة تسجيل الدخول للحصول على التوكن الجديد

#### 4. لا يعمل ماسح الباركود
- امنح أذونات الكاميرا للمتصفح
- استخدم HTTPS (QuaggaJS لا يعمل على HTTP)
- تأكد من إضاءة جيدة وباركود واضح
